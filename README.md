# Dead Branch para Foundry VTT

Módulo do [Foundry Virtual Tabletop](https://foundryvtt.com) que integra o Foundry ao Dead Branch,
gestor de fichas de RPG para Web e Android.

> Este repositório só publica os releases do módulo. O desenvolvimento acontece em outro
> repositório, e cada versão chega aqui automaticamente.

## Instalação

1. No Foundry, abra **Módulos complementares** > **Instalar módulo**.
2. Cole a URL do manifest no campo **URL do manifest** e clique em **Instalar**:

   ```text
   https://github.com/igoramaral/deadbranch-foundry/releases/latest/download/module.json
   ```

3. Ative o módulo "Dead Branch" no seu mundo.

O Foundry avisa quando sair uma versão nova.

## Compatibilidade

| Foundry VTT | Suporte                 |
| ----------- | ----------------------- |
| v14         | Sim (versão verificada) |
| v13         | Sim                     |

Suportamos a versão principal atual do Foundry e a anterior.

## English

Foundry VTT module that connects Foundry to Dead Branch, a character sheet manager for the Web and
Android. Install it from **Add-on Modules > Install Module** with the manifest URL:

```text
https://github.com/igoramaral/deadbranch-foundry/releases/latest/download/module.json
```

Supports Foundry VTT v13 and v14.
